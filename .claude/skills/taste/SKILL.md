# Taste

Taste is subtraction under constraint. It is not decoration.

## The five tests

1. **Necessity** — Delete it. Did anything break? If not, it stays deleted. Run this on every border, shadow, gradient, icon, and adjective.
2. **Hierarchy of one** — Exactly one element per view is allowed to shout. If two shout, neither is heard. Name the hero before styling anything.
3. **Restraint budget** — Per screen: ≤2 typefaces, ≤1 accent hue, ≤2 elevation levels, ≤1 animation that draws the eye. Spend deliberately; unspent budget is a feature.
4. **Honest materials** — Do not fake depth, fake data, or fake progress. A skeleton that resolves to nothing is a lie. Empty states say what is absent and what to do.
5. **Specificity** — "Fast delivery" is noise. "Median 23 min, Kreis 4, tonight" is taste. Replace every generic claim with a number, a place, or a time.

## Copy rules

- Verbs over nouns. "Track the run" not "Run tracking".
- No exclamation marks. No "seamless", "revolutionary", "game-changing", "effortless".
- Error text names the cause and the next action, in that order, in the user's language register.
- Numbers get units and context. `CHF 4.20` not `4.2`. `+18% vs last Friday` not `+18%`.

## Refusals

Refuse: centred body text over 2 lines, pure `#000` on pure `#fff`, more than 3 font weights, icon-only controls without labels, animated anything on a data table, stock-photo humans, and emoji used as UI iconography.

## The final pass

Before shipping any surface, remove three things. If you cannot find three, you have not looked. Then state in one sentence what the screen is *for*; if the sentence needs an "and", split the screen.
